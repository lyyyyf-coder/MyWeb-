# 提瓦特导览 · 使用说明

这是一套已经能跑的网页作业，共 **5 个页面**，主题是《原神》旅行笔记。
下面按"先看 → 再换 → 后上传"的顺序讲，每一步都写到鼠标点哪里。

---

## 一、先看看它长什么样

1. 打开文件夹 `GenshinWeb`（就是当前这个文件夹）。
2. 找到 **index.html**，**双击**它。
3. 浏览器会打开首页。鼠标滚轮往下滚，能看到数据条、七国卡片、三个入口卡片、页脚。
4. 点导航栏上的「旅行者档案」「角色与深渊」「提瓦特风光」「冒险家协会」，能进到各个分页。
5. 每个分页的页头下面都有一个 `← 返回首页`，点它就能回来。

如果双击后显示的是记事本里的代码，不是网页：右键 `index.html` → 打开方式 → 选 Edge 或 Chrome → 勾选"始终使用此应用打开"。

## 二、换成你自己的东西

图片已经全部换成你自己的截图（11 张，共约 1.3 MB）。下面这张表说明每个文件名对应哪张图，以后想换照旧覆盖同名文件即可。

### 2.1 换图片（最重要，也最省事）

规则只有一条：**文件名不要改，直接用新图覆盖旧图**。代码里写死了这些文件名，你只要把同名文件换掉，页面自动就变了。

| 文件名 | 出现在哪里 | 建议尺寸 | 放什么 |
|---|---|---|---|
| `image/banner.jpg` | 首页首屏大图 + 4 个分页的页头背景 | 1600×900 横图 | 云海那张（已放入，由 g3 裁切压暗） |
| `image/avatar.jpg` | 首页第一张卡片、档案页左侧 | 800×800 方图 | 温迪同人图（已放入） |
| `image/char1.jpg` | 角色页第 1 张、首页第 2 张卡片 | 1080×720 | 万叶同人图（已放入） |
| `image/char2.jpg` | 角色页第 2 张 | 1200×554 | 爱可菲立绘（已放入） |
| `image/char3.jpg` | 角色页第 3 张 | 1200×554 | 秘境实战截图（已放入） |
| `image/g1.jpg` ~ `g6.jpg` | 相册页 6 张 + 首页第 3 张卡片 | 1280 宽横图 | 雪山落日 / 水边黄昏 / 云海浮岛 / 璃月港夜色 / 沙漠之夜 / 水面天空（已放入） |

具体操作（Windows）：

1. 截图：按 `Win + Shift + S` 框选，图片会进剪贴板；或者游戏里截图后去截图文件夹找。
2. 想把图片存成 jpg：打开图片 → 右上角「…」→ 另存为 → 保存类型选「JPEG」。
3. 把新图片**重命名**成 `banner.jpg`（注意是 `.jpg` 不是 `.png`）。
4. 拖进 `GenshinWeb/image` 文件夹，弹出"是否替换"时点**替换**。
5. 回到浏览器按 `F5` 刷新，就能看到新图。如果还是旧的，按 `Ctrl + F5` 强制刷新。

小技巧：图片别太大。手机拍的照片动辄 4MB，网页会变慢。裁到上面建议的尺寸就够了。

### 2.2 改文字

用**记事本**就能改，但推荐装一个免费编辑器 **VS Code**（搜索 `Visual Studio Code` 官网下载），中文显示和替换都更好用。

用记事本改的步骤：

1. 右键某个 `.html` 文件 → 打开方式 → 记事本。
2. 按 `Ctrl + F` 搜索要找的词，比如 `优游a5`，把它改成你自己的游戏 ID。
3. 改完按 `Ctrl + S` 保存。
4. **保存时如果弹出"编码"选择，一定要选 UTF-8**，否则中文会变成乱码。

每一页值得动的地方：

| 页面 | 搜什么关键词 | 改成 |
|---|---|---|
| 全部 5 页 | `姓名：李奕霏` `学号：U202615163` `班级：计算机2608 班` | 已填好，如有错自己改 |
| `index.html` | `提瓦特漫游指南`、副标题那段 | 你自己的网站名和一句话简介 |
| `index.html` | `1200+` `2000+` `36` `7` | 你自己的真实数字 |
| `web/about.html` | `优游a5`、`2024 / 07` 等时间轴 | 你的游戏 ID 和真实经历 |
| `web/hobby.html` | `第 12 期` 那些表格行 | 你自己的深渊记录 |
| `web/gallery.html` | `01 · 雪山落日` 等 6 条说明 | 对应你换上去的截图内容 |
| `web/contact.html` | `xxx@example.com`、`github.com/你的用户名` | 你的真实联系方式 |

**建议**：至少把时间轴那几段改成你真发生过的事。老师如果随口问一句"这段是真的吗"，你要能答得上来。

### 2.3 改配色（可选，不改也好看）

打开 `web/style.css`，最上面第 8 行左右有这么一段：

```css
:root {
  --navy: #16324f;      /* 深色主色：导航、页脚、标题 */
  --gold: #c8a44d;      /* 金色点缀：按钮、小标题、圆点 */
  --cream: #faf6ec;     /* 页面背景 */
  --paper: #fffdf7;     /* 卡片背景 */
}
```

把 `#16324f` 换成别的色号，整站主色就变了。改之前先把 `style.css` 复制一份备份，改坏了能还原。

## 三、上传到 GitHub，拿到主页链接

作业要的是 `https://你的用户名.github.io/仓库名/` 这样的地址。全程在网页上点，不用装软件。

### 3.1 注册账号

1. 打开 https://github.com ，点右上角 `Sign up`。
2. 填邮箱、密码、用户名（**用户名会用进网址里**，建议用拼音或英文，别用中文）。
3. 邮箱会收到验证码，填进去，注册完成。

### 3.2 新建仓库

1. 登录后点右上角 `+` → `New repository`。
2. `Repository name` 填 **MyWeb**（这就是网址最后那一段）。
3. 选 `Public`（私有仓库用不了免费的 Pages）。
4. **下面三个勾都不要勾**（尤其不要勾 Add a README file）。
5. 点 `Create repository`。

### 3.3 把文件传上去

1. 新仓库页面上有一行 `uploading an existing file`，点它。（也可以点 `Add file` → `Upload files`）
2. 打开电脑上的 `GenshinWeb` 文件夹。
3. **按 `Ctrl + A` 全选里面的三个东西**（`index.html`、`web` 文件夹、`image` 文件夹），一起拖进浏览器网页里的上传框。

   ⚠️ 最容易错的一步：**要拖"里面的东西"，不要拖 `GenshinWeb` 文件夹本身**。
   拖文件夹本身的话，文件会变成 `仓库/MyWeb/index.html`，网址就会多一层，Pages 打开是 404。

4. 等进度条走完，下面的 `Commit changes` 按钮变亮，点它。

### 3.4 开启 Pages（发布网页）

1. 在仓库页面点 `Settings`（齿轮图标）。
2. 左边栏往下找 `Pages`，点进去。
3. `Source` 选 `Deploy from a branch`。
4. `Branch` 选 `main`，右边目录选 `/ (root)`，点 `Save`。
5. 等 1~2 分钟，刷新这个页面，顶部会出现一行：
   `Your site is live at https://你的用户名.github.io/MyWeb/`
6. 点这个链接。能看到首页，就成功了。

### 3.5 上传后自己检查一遍

拿这个地址，把这几个动作都点一遍：

- [ ] 首页能打开，大图和卡片都在
- [ ] 导航栏 4 个分页都能点进去
- [ ] 每个分页的「← 返回首页」都能回到首页
- [ ] 图片全部显示（没有出现破图的小方块）
- [ ] 用手机打开同一个地址，排版没有错乱

## 六、常见问题

**图片显示不出来，只有一个方框**
文件名对不上。检查三件事：扩展名是不是 `.jpg`（`.JPG` 也不行）、有没有多打空格、字母大小写是否一致。GitHub Pages 跑在 Linux 上，**区分大小写**。

**页面中文变成乱码**
保存时编码选错了。用记事本重新打开 → 另存为 → 编码选 `UTF-8` → 覆盖保存。

**Pages 打开显示 404**
三种可能：① 刚保存，等 1~2 分钟再看；② `index.html` 不在仓库最外层（多半是拖文件夹本身导致的）；③ Settings 里 Branch 没选 `main` 或目录没选 `/ (root)`。

**网页打开了但没有任何样式，全是黑字白底**
`web` 文件夹没传上去，`style.css` 找不到。回仓库确认根目录下有 `web` 这个文件夹。

**改完文件再上传，网页没变**
浏览器缓存。按 `Ctrl + F5` 强制刷新；GitHub 那边也需要 1 分钟重新发布。

**作业要求文件夹叫 MyWeb，我这个叫 GenshinWeb**
交之前右键重命名成 `MyWeb` 就行。仓库名建议也用 `MyWeb`，这样网址是 `https://用户名.github.io/MyWeb/`，和文件夹名一致，看起来更规整。

## 七、关于原创和素材

- 页面代码（HTML / CSS / JS）全部是手写原创，没有套用任何现成模板，可以直接用作作业提交。
- 图片都是你自己的游戏截图，属于个人游玩记录，页脚已经注明"仅供学习交流使用"。
- 游戏角色、场景的美术版权属于游戏公司。这份作业属于非商业的个人分享，通常没有问题；如果老师对素材来源要求严格，可以把图片换成自己拍的生活照，页面结构不用动。
